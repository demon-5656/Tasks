# Мои заметки по ДЗ 5

Это ДЗ уже больше про командную работу, а не просто “создай ВМ”.

Главные темы:

- state надо хранить не на локальном ПК;
- state надо блокировать, чтобы два человека не сделали `apply` одновременно;
- код надо гонять через линтеры;
- секреты нельзя тащить в git.

## Remote state

Локальный `terraform.tfstate` норм, пока ты один и просто учишься. В команде это быстро ломается: один сделал apply, второй у себя не обновил state и пошел менять то же самое.

Remote state решает это тем, что state лежит в одном месте. В этом задании это Yandex Object Storage, совместимый с S3.

## Lock

Lock нужен, чтобы Terraform не дал двум процессам одновременно писать state.

Я открыл `terraform console`, он взял lock. Потом во втором окне запустил `terraform apply`, и Terraform честно упал с ошибкой `Error acquiring the state lock`.

Это нормальное поведение. Лучше получить такую ошибку, чем раздолбать state.

## force-unlock

`force-unlock` нужен, если lock завис. Например, процесс умер, ноут выключился, сеть отвалилась.

Команда опасная:

```bash
terraform force-unlock -force <LOCK_ID>
```

Её надо делать только если точно понятно, что никто сейчас не делает apply.

## tflint и checkov

`tflint` больше про качество Terraform-кода:

- версии providers;
- неиспользуемые переменные;
- странные module source.

`checkov` больше про безопасность:

- public IP;
- security groups;
- storage/security-настройки.

В этом ДЗ `checkov` заставил убрать public IP и добавить security group. Для боевого кода это норм, но в учебных заданиях иногда public IP нужен, чтобы просто подключиться и проверить.

## Validation

Validation в переменных полезна, чтобы ошибка была сразу на входе.

Например, если ожидается IP, лучше упасть на `terraform plan`, чем потом долго искать, почему облако не приняло ресурс.

## Что не надо коммитить

Не коммитить:

- `backend.hcl`;
- `personal.auto.tfvars`;
- `terraform.tfstate`;
- `.terraform/`;
- access keys;
- service account json;
- plans.

Я всё это оставил локально и исключил через `.git/info/exclude`.
