# Учебные работы Netology

В каталоге собраны домашние работы по инфраструктуре, автоматизации, мониторингу и микросервисам.

## Подход к выполнению заданий

1. Сначала разбираю формулировку задания и материалы занятия. Отдельно отмечаю обязательные и необязательные пункты.
2. Для технических решений сравниваю несколько подходящих продуктов по критериям из задания. Возможности и ограничения проверяю по актуальной документации.
3. Решение пишу простым языком и привязываю к условиям задачи. Не добавляю функции только ради более длинного ответа.
4. В теоретических работах оставляю только ответ. Ссылки для отправки, скриншоты, служебные заметки и описание процесса подготовки в решение не включаю.
5. В практических работах добавляю исходники, конфигурацию и результаты проверки только тогда, когда они действительно требуются заданием.
6. Перед публикацией провожу три проверки:
   - техническую — все требования закрыты, а утверждения не обещают больше, чем даёт выбранный продукт;
   - редакционную — нормальная грамматика, единые термины и стиль прошлых работ;
   - артефактную — нет лишних ссылок, скриншотов, скрытых символов, временных файлов и служебного текста.
7. После исправлений проверяю Markdown, состояние Git и содержимое файла в удалённом репозитории.

## Структура работы

Для каждого задания создаётся отдельный каталог с понятным именем. Основной ответ хранится в `README.md`. Дополнительные каталоги появляются только у практических работ, если нужны конфигурации, исходный код или подтверждение запуска.
